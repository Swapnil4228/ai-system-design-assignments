# AI System Design Assignments

This repository contains AI/ML workflow design assignments and small prototype implementations for enterprise system monitoring and intelligent IT ticket classification.

- Telemetry preprocessing

### 2. Intelligent IT Ticket Auto-Resolution System
- NLP-based ticket classification
- OCR handling for screenshots
- TF-IDF + Logistic Regression prototype
